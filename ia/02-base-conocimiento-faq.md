## CONTROL DE PLAGAS

**¿Qué incluye la fumigación?**
Aplicación por aspersión con producto líquido para el control de insectos en
general. Diseñada para controlar plagas como:
- Cucarachas
- Hormigas
- Arañas
- Alacranes
- Otros insectos rastreros comunes

**¿Qué NO incluye la fumigación?**
La fumigación convencional NO incluye plagas especiales como:
- Termitas
- Abejas
- Avispas
- Palomas
- Murciélagos

Estas requieren un tratamiento especializado y una **cotización independiente**.

**¿Cuánto tiempo debo esperar para entrar nuevamente?**
El tiempo recomendado de reingreso es de aproximadamente **2 horas** después de
la aplicación.

**¿Cuánto tarda la fumigación?**
Duración aproximada de **40 minutos**, aunque puede variar según el tamaño del
inmueble.

## LIMPIEZA DE TANQUES DE AGUA Y CISTERNAS

**¿Cómo realizan la limpieza?**
1. Extraer completamente el agua mediante una bomba sumergible.
2. Raspar paredes y piso para retirar residuos.
3. Aplicar productos desincrustantes para eliminar el sarro.
4. Enjuagar completamente el tanque.
5. Retirar nuevamente toda el agua.
6. Realizar una desinfección con cloro.
7. Llenar nuevamente el tanque de agua.

Este mismo procedimiento aplica para las cisternas.
